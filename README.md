# Furniture Store

A small offline mobile app built with Expo, React Native, and TypeScript.

## Install

```powershell
npm install
```

## Run

```powershell
npm run dev
```

For web:

```powershell
npm run web
```

## Test

```powershell
npm run typecheck
npx expo export --platform web
```

## Demo Login

Use any non-empty username and password.

## Included

- Splash screen
- Login and registration screens
- Home screen with local product data
- Favorites screen with local data
- Product detail screen
- Profile screen with local data

## Structure

```text
assets/     Images and app assets
src/        App source code
App.tsx     App entry point
```
